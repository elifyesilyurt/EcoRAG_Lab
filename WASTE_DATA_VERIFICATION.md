# Operational waste source audit

Source: 2026 Environmental Data Fact Sheet, Tables 9 and 10, pages 7–8, and inventory methodology on page 11. The exact PDF version is hash-locked by the ingestion provider.

The previous FY25 total of 265,000 mt, diversion of 218,000 mt and rate of 82.3% were unsupported. Table 9 reports 58,868 mt generated, 36,149 mt diverted and 22,719 mt directed to disposal. The calculated diversion ratio is 61.41%, not a reported achievement percentage or target. Non-hazardous landfill is a separate 21,540 mt category; it must not represent all disposal.

All six FY20–FY25 inventory columns are now transcribed from Table 9. Site-count and certification-tier assertions are removed from the provider until audited; unavailable counts are not zero. Table 10's on-site prevention (FY24 5,382 mt; FY25 7,646 mt) is a separate provider and is never added to off-site diversion.

FY25 adds cloud hardware packaging to inventory, without adjusting earlier years. The inventory excludes construction/deconstruction. These qualifications are included in static summaries and each audited waste retrieval row, so year-over-year differences must not be described as comparable operational performance changes without qualification.

Dashboard, bilingual summaries and contextual insight use shared providers. The actual embedding model was used for new evidence, retaining exact-content vectors from the same model. The atomic index now contains 1,588 chunks, including 32 audited rows. Independent source-value, reconciliation, missing-period, missing-certification, bilingual-summary and zero-denominator tests cover these changes. Real answer generation remains a separate evaluation step; carbon removal is still pending.
